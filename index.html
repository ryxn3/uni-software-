    > ABOUT
    
        
    
          devterm
          
    DEVTERM is a text-first, terminal-styled configuration console for gaming mice and keyboards — modeled after vendor tools like Razer Synapse, Logitech G HUB and the MCHOSE driver suite, reimagined as a single all-text web app.
    
          
    On the SCAN screen it uses the browser's WebHID API to look for mice and keyboards actually connected to this computer, and only shows configuration for what it finds. The first scan on a new device needs one click to grant permission (a browser security requirement); after that, DEVTERM re-detects it silently on every visit. Vendor drivers usually block raw feature-report access from the web, so a recognized brand loads a full simulated profile, and anything else falls back to a generic profile you can still fully configure.
    
          
    Everything runs client-side — no server, no account. Device state is stored in localStorage and exportable as JSON from the PROFILES screen.
    
          
    Type help in the command line below for shell-style navigation.
